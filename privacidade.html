Política de Privacidade

Ponto ALEP — Saldo de Horas · última atualização: agosto de 2026

Esta extensão para Google Chrome calcula, direto na página de Consulta de Marcações de Ponto do Portal RH da Assembleia Legislativa do Paraná, o saldo de horas do usuário (Horas Mês, Horas Necessárias, Horas Trabalhadas e Saldo). Esta página explica quais dados a extensão usa, para quê, e como eles são tratados.

Quais dados a extensão coleta

DadoQuandoPara quêOnde fica
Tabela de marcações de ponto (datas, horários, ocorrências) Sempre que a página de Consulta de Ponto é aberta Calcular o saldo de horas — processamento 100% local, no navegador Nunca sai do navegador do usuário
Nome e e-mail Somente se o usuário usar "Solicitar uma licença" dentro da extensão Gerar e enviar por e-mail a chave de acesso da extensão Backend próprio (Supabase), usado só para emitir/validar a licença
Identificador de dispositivo (gerado aleatoriamente, ex.: dev-xxxx-xxxx) Na ativação da licença Controlar em qual computador a licença está ativa (1 computador por vez) Backend próprio (Supabase)
Configurações e exceções cadastradas (jornada diária, feriados editados, recessos, expedientes especiais) Quando o usuário cadastra ou altera algo no painel Lembrar as preferências do usuário entre sessões Somente chrome.storage.local, no próprio navegador

O que a extensão NUNCA faz

Não vende, não compartilha e não transfere dados para terceiros fora do necessário para a extensão funcionar. Não usa os dados para publicidade, para determinar crédito/empréstimo, nem para qualquer finalidade fora do propósito único descrito acima. Não lê e-mails, histórico de navegação, localização ou qualquer conteúdo fora da página de Consulta de Marcações de Ponto do Portal RH.

Código remoto

A extensão não executa código remoto. Todo o código roda a partir dos arquivos empacotados (Manifest V3); as chamadas de rede retornam apenas dados em JSON.
